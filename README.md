# Coffee Website

A responsive coffee shop landing page built with HTML, CSS, and JavaScript. This project was created while following a YouTube front-end tutorial to practice modern page layouts, styling, and mobile navigation.

**Live Site:** [sandipbeghaa.github.io/coffee-website](https://github.io)

## What's Inside

- **Responsive Navigation Bar:** Adapts smoothly between desktop menus and mobile screens.
- **Hero & Menu Sections:** Styled product cards, coffee menu highlights, and customer review sections.
- **Contact & Footer Layout:** Clean multi-column footer and contact section built with CSS Flexbox and Grid.

## Built With

- HTML5
- CSS3
- JavaScript

## How to Run It Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com
   ```
2. Open the `coffee-website` folder.
3. Double-click `index.html` to open it in your browser.

## What I Practiced & Learned

- Structuring a complete multi-section landing page using semantic HTML.
- Building responsive layouts, hover effects, and typography hierarchy with CSS.
- Deploying a static website live using GitHub Pages.
